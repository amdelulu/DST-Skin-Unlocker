DST Offline All-Skins Patch

A local patch for Don’t Starve Together designed to unlock skins for offline use.

Features

* Local skin unlocking for offline gameplay.
* Designed for personal offline use.
* Simple installation and setup.
* Support and updates for project contributors.

Installation

1. Download the patch files.
2. Back up any original files that will be modified.
3. Follow the setup instructions included with the patch.
4. Launch Don’t Starve Together in offline mode and test the changes.

Note: Detailed installation commands will be added when the actual patch files are available.

Troubleshooting

Skins remain locked

* Verify that the patch was installed in the correct location.
* Confirm that the game version is supported.
* Check that all required files are present.

The game fails to launch

* Restore the original files from your backup.
* Test the game without the patch.
* Contact me on Telegram if you need help.
